# AI-Redox
AI-Redox integrates machine learning, DFT, thermodynamic analysis and experimental validation to predict key properties of metal oxides and identify efficient, low-cost materials for high-temperature green hydrogen production. Its open repository will accelerate sustainable redox-material discovery
